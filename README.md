# ExperiStay

ExperiStay é uma plataforma web para busca e anúncio de imóveis por temporada, focada em proporcionar experiências únicas aos viajantes em destinos especiais do Brasil.

O projeto busca transmitir uma "vibe" de modernidade e conforto em seu design. Com padronização de cores, contraste de texto e feedback instantêneo visa seguir padrões de qualidade de usabilidade.

Para visualizar o projeto 👉 [Deploy](https://experi-stay.vercel.app/)

## Funcionalidades disponibilizadas
As funcionalidades ainda não foram criadas, temos apenas a criação da landing page.

## Funcionalidades a serem implementadas
- Registro e autenticação de usuários
- Registro de imóveis
- Consultas de imóveis por disponibilidade
- Avaliação de imóveis por parte dos usuários
- Usuários poderão definir imóveis como favorito
- Usuários poderão reservar imóveis na data escolhida

## Como funciona

- **Busca de imóveis**: Usuários podem pesquisar propriedades disponíveis por data e localização, visualizando destaques, experiências e avaliações reais.
- **Experiências exclusivas**: Cada imóvel oferece acesso a atividades diferenciadas, como passeios, retiros e aulas gastronômicas.
- **Anúncio de imóveis**: Proprietários podem cadastrar seus imóveis e se juntar à comunidade de anfitriões ExperiStay.
- **Interface responsiva**: O site adapta-se para desktop e mobile, garantindo navegação fluida em qualquer dispositivo.

## Tecnologias utilizadas

- **React**: Biblioteca para construção de interfaces dinâmicas e reativas.
- **TypeScript**: Tipagem estática para maior segurança e produtividade no desenvolvimento.
- **Vite**: Ferramenta de build rápida, com HMR (Hot Module Replacement) e configuração simplificada.
- **Material UI (MUI)**: Componentes visuais modernos e personalizáveis, com suporte a temas e responsividade.
- **Swiper**: Carrossel responsivo para navegação entre experiências, avaliações e imóveis.
- **Moment.js**: Manipulação de datas para filtros e seleção de períodos.
- **GSAP**: Animações suaves para transições e efeitos visuais.
- **React Router**: Gerenciamento de rotas e navegação entre páginas.
- **React Lazy Load Image**: Carregamento otimizado de imagens pesadas.

## Vantagens das tecnologias

- **Performance**: Vite e React garantem carregamento rápido e atualização instantânea durante o desenvolvimento.
- **Escalabilidade**: TypeScript facilita manutenção e evolução do código, reduzindo erros.
- **Experiência do usuário**: MUI e GSAP proporcionam uma interface agradável, moderna e animada.
- **Responsividade**: O layout se adapta a diferentes tamanhos de tela, melhorando a usabilidade.
- **SEO e acessibilidade**: Estrutura pensada para boa indexação e navegação acessível.

## Como rodar o projeto

1. Faça um clone do projeto:
     ```sh
     git clone https://github.com/Leonardobern10/ExperiStay
     ```
2. Acesse a pasta:
     ```sh
     cd ExperiStay
     ```
3. Instale as dependências:
   ```sh
   npm install
   ```
4. Inicie o ambiente de desenvolvimento:
   ```sh
   npm run dev
   ```
3. Acesse [http://localhost:5173](http://localhost:5173) no navegador.

## Scripts disponíveis

- `npm run dev`: Inicia o servidor de desenvolvimento.
- `npm run build`: Compila o projeto para produção.
- `npm run preview`: Visualiza o build de produção localmente.
- `npm run lint`: Executa o linter.
- `npm run format`: Formata o código com Prettier.
